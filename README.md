# Geoguessr Guessing Neural Network
This is a convolutional neural network (CNN) thats trained on the [GeoLocation](https://www.kaggle.com/datasets/ubitquitin/geolocation-geoguessr-images-50k/data) dataset from Kaggle. It takes in an image from a random place in the world and outputs the country that the image is taken from.

Developed by Ehan Haque and Nirmal Lamichhane for CS3540.
